# ReproBug

Smart browser error reporting and reproduction platform.

## Status

Initial project setup. The React dashboard and Express API scaffold are the first milestone; database persistence, authentication, browser extension capture, issue fingerprinting, tests, and deployment are planned next.

## Planned stack

- React + JavaScript + Vite
- Node.js + Express
- PostgreSQL + Prisma
- Chrome Extension Manifest V3

## Roadmap

1. Dashboard and API foundation
2. PostgreSQL schema and Prisma migrations
3. Authentication, authorization, and validation
4. Browser extension diagnostic capture with sensitive-data redaction
5. Error fingerprints and duplicate grouping
6. Analytics and reproduction guidance
7. Automated tests and CI
8. Deployment, documentation, screenshots, and demo
